# P1 — Configuration PC professionnelle

## 🎯 Objectif

Sélectionner et justifier le choix des composants d'un PC
pour un usage professionnel CAO/DAO sous AutoCAD.

## 👤 Profil client

- Usage professionnel uniquement
- Design sobre, sans LED
- Budget : 2 000€ HT
- Logiciel principal : AutoCAD (Autodesk)
- Carte graphique professionnelle CAO/DAO
