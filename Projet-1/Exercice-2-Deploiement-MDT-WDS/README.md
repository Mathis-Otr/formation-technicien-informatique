# 🖥️ Exercice 2 – Déploiement automatisé Windows 11 avec MDT/WDS

## 📋 Objectif
Mettre en place un serveur de déploiement Windows 11 automatisé
en entreprise, utilisable sur plusieurs machines simultanément.

## 👤 Contexte
Dans le cadre d'une entreprise, déployer manuellement Windows sur
chaque poste est long et source d'erreurs. MDT et WDS permettent
d'automatiser ce processus depuis un serveur central.

## 🛠️ Technologies utilisées
- Windows Server
- MDT (Microsoft Deployment Toolkit)
- WDS (Windows Deployment Services)
- Machine virtuelle (VirtualBox)

## ✅ Compétences mises en œuvre
- Installation et configuration d'un serveur MDT/WDS
- Création d'une séquence de tâches personnalisée
- Génération d'une image de démarrage réseau
- Capture d'une image master Windows 11
- Déploiement automatisé clé en main sur une nouvelle machine

## 📁 Structure du dossier
- `docs/` – captures d'écran des étapes
- `scripts/` – séquences de tâches MDT
- `rapport/` – compte-rendu du projet

## 🔗 Résultat
Déploiement fonctionnel de Windows 11 prêt à l'emploi
sur une nouvelle machine via un serveur MDT/WDS configuré de A à Z.
